# **App Name**: Prooflight

## Core Features:

- NFT Dashboard: Dashboard to view, share, and check the status of owned NFTs via public link.
- NFT Verification: A 'Verify NFT' page where anyone can paste an NFT ID or public address to validate the authenticity of a digital proof.
- AI Assisted Proof Reasoning: Use AI as a tool to provide reasoning whether the given proof of ownership/authenticity makes sense for the stated identity.

## Style Guidelines:

- Primary color: Moderate cyan (#46B8C1) evoking trust and technology.
- Background color: Light cyan (#E0F8FA), for a clean, unobtrusive background.
- Accent color: Green-cyan (#6DDA79), used to highlight interactive elements and successful validations.
- Body and headline font: 'Inter' sans-serif font for clear and modern readability.
- Use clean, minimalist icons for representing credentials, ownership, and verification status.
- Employ a grid-based layout to maintain structure and readability across all screen sizes.
- Subtle transitions and animations to provide feedback on interactions and validations.
